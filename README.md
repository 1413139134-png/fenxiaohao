## 产品简介

分小号面向**运营商号卡 / 宽带业务**，提供**企业级号卡管理 + 智能分销**一体化 SaaS：

- **上游**：对接运营商 / 供应商（号卡、宽带产品）
- **下游**：服务分销商 / 代理商（接单、推广、获佣）
- **平台能力**：选号、资格校验、开卡、发货、多级分销、佣金结算、店铺装修、H5 下单、落地页与集合页海报、自主对接渠道商 API 等全链路能力

### 核心功能

- **智能分销系统**：多级分销、自动佣金结算、分销数据统计、分销商管理
- **订单全链路管理**：自动提单、状态跟踪、物流管理、异常订单处理
- **产品管理中心**：产品分类、价格策略、库存监控、产品权限与供应商管理
- **可视化页面装修**：拖拽式编辑、实时预览、丰富组件与模板，落地页与集合页海报
- **自主对接渠道**：通过「我的接口」与「渠道配置」自主配置查号、下单、查单等 API
- **自动化与安全**：定时任务、自动提单、数据加密、权限控制、高可用保障
